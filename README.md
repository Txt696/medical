# АптекаСправка

Аптечная справочная: посетители ищут лекарство и сравнивают цены во всех аптеках
(как GoodRx или Tabletki.ua), а аптеки сами ведут свои товары через личный кабинет.

## Возможности

**Для посетителей**
- поиск по торговому названию, действующему веществу (МНН) и производителю, подсказки при вводе, поиск с опечатками;
- карточка препарата: цены во всех аптеках от дешёвых к дорогим, «лучшая цена», размер экономии, наличие, телефон;
- аналоги с тем же действующим веществом;
- фильтры по категории и городу, только «в наличии», сортировка по цене;
- каталог от А до Я, список аптек, страница аптеки со всеми её товарами;
- адаптивная вёрстка для телефона.

**Для аптек** (`/login` → кабинет)
- добавление товара вручную: выберите препарат из общего каталога (автоподсказка) или создайте новую карточку;
- **импорт прайс-листа текстом** или файлом CSV/TXT:
  - таблица из Excel/Google Таблиц с заголовком (колонки в любом порядке);
  - таблица без заголовка (последние две колонки — цена и остаток);
  - свободный текст: `Парацетамол таб. 500мг №20 — 25.50` (форма, дозировка и упаковка выделяются автоматически);
  - перед загрузкой показывается проверка: что будет создано, какие цены обновятся, какие строки с ошибкой;
  - режимы «добавить/обновить» и «полная замена»;
  - остатки: заменить значениями из файла или прибавить к текущим (приход товара);
- быстрое редактирование цен и остатков в таблице, выгрузка своего прайса в CSV;
- редактирование профиля аптеки (адрес, телефон, часы работы).

**Для администратора**
- создание аптек и логинов для них, сброс паролей, скрытие аптеки с сайта;
- редактирование общего каталога препаратов, объединение дубликатов;
- импорт и правка товаров от имени любой аптеки;
- настройки сайта: название, слоган, валюта.

## Запуск

Нужен Node.js 22.13 или новее (используется встроенный SQLite, отдельная база данных не нужна).

```bash
npm install
npm run seed     # необязательно: демо-аптеки и препараты
npm start        # http://localhost:3000
```

С демо-данными:
- администратор `admin` / `admin123`;
- аптеки `zdorovie`, `farmplus`, `social5`, `vita` с паролем `demo123`.

Без `seed` при первом запуске создаётся администратор, его пароль печатается в консоль
(или задаётся через `ADMIN_LOGIN` / `ADMIN_PASSWORD`). **Смените демо-пароли перед публикацией.**

### Переменные окружения

| Переменная | Значение |
|---|---|
| `PORT` | порт, по умолчанию 3000 |
| `DB_PATH` | путь к файлу базы, по умолчанию `data/pharmacy.db` |
| `ADMIN_LOGIN`, `ADMIN_PASSWORD` | первый администратор |
| `COOKIE_SECURE=1` | включить при работе по HTTPS |
| `TRUST_PROXY=1` | если сайт стоит за nginx/прокси |

### Тесты

```bash
npm test
```

## Устройство

```
src/server.js        маршруты (Express)
src/db.js            схема SQLite, каталог препаратов, пароли
src/importer.js      разбор прайс-листа из текста
src/views/           HTML-шаблоны (публичная часть и кабинет)
public/              CSS и JS (подсказки, загрузка файла)
scripts/seed.js      демо-данные
```

Препараты хранятся в общем каталоге: одна карточка (название + форма + дозировка + упаковка)
и цены разных аптек к ней. Поэтому при импорте «Парацетамол таб. 500мг №20» от разных аптек
попадает в одну карточку, и цены можно сравнивать.
