## Структура

| Путь | Что там |
|---|---|
| `src/server.js` | маршруты, сессии, CSRF, импорт, настройки |
| `src/db.js` | схема SQLite, миграции, поиск/сопоставление препаратов, остатки |
| `src/importer.js` | разбор импортируемого текста (заголовки на 3 языках) |
| `src/i18n.js`, `src/locales/` | переводы |
| `src/phones.js` | несколько телефонов аптеки |
| `src/views/` | HTML-шаблоны (layout, public, admin) |
| `public/` | style.css, app.js, logo.svg |
| `scripts/seed.js` | демо-аптеки и 36 препаратов |
| `test/` | тесты node:test |
